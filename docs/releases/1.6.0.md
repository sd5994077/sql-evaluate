# SQL Evaluate 1.6.0

Released 2026-09-07.

## Added

- Portable, sensitive cross-case Investigation History archives.
- Server-aware and portable-target recurrence summaries with distinct-capture denominators.
- Structured Showplan database, table, index, and optimizer-statistics extraction.
- Read-only statistics verification and guarded multi-server Ola Hallengren previews.

## Safety boundaries

- No SQL Server connection or SQL execution was added to SQL Evaluate.
- Cases without server identity are excluded from recurrence totals.
- Repeated observations are not presented as proven causes.
- Ola scripts default to report-only mode, disable fragmentation work, and reject unverified servers.
