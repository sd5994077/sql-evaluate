# SQL Evaluate 1.4.0

Release date: 2026-09-03

- Added an importable server-capability snapshot for SQL Server version, edition, database, permissions, existing plan-history features, and installed diagnostic tools.
- Added a curated First Responder Kit, sp_WhoIsActive, Ola history, and native DMV catalog with explicit safety boundaries.
- Added capability-aware Spill Triage plan acquisition using exact `plan_handle` provenance, last-known actual plans, Query Store, controlled capture, and approved Extended Events.
- Added a SQL Server 2022-aware Query Store export with one row per plan, direct Query Store query/plan hashes, database identity, persisted compile Showplan, and weighted runtime aggregates. Newly enabled stores are explicitly limited to post-enable history.
- Added provenance-aware CSV/XLSX Showplan import so stable identity from the result row can correlate an otherwise identity-free plan without modifying or guessing from SQL text.
- Added Deep Analysis case schema 1.4 with backward migration and persisted capability evidence.
